# 🎣 Fishing Store — Интернет-магазин для рыболовов

Веб-приложение для продажи рыболовных товаров с интеграцией RAG-бота, Telegram-уведомлениями и лунным календарём рыболова.

## ✨ Возможности

### Для пользователей:

#### 🛒 Каталог товаров
На сайте реализован полный каталог рыболовных товаров с возможностью:
- Фильтрации по категориям (удочки, катушки, лески, приманки и др.)
- Поиска по названию товара через поисковую строку
- Просмотра детальной информации о товаре (фото, описание, цена, старая цена для скидок)
- Отображения товаров со скидкой (зачёркнутая старая цена)

#### 🛒 Корзина и оформление заказов
Реализована полноценная корзина с функциями:
- Добавление товаров из каталога и карточки товара
- Изменение количества товаров (увеличение/уменьшение)
- Удаление товаров из корзины
- Подсчёт общей суммы заказа в реальном времени
- Оформление заказа с выбором типа доставки и способа уведомления

#### 🌙 Лунный календарь рыболова
На главной странице реализован интерактивный календарь с прогнозом клёва:
- **Расчёт фазы луны** — алгоритм вычисляет текущую фазу на основе даты новолуния 1970 года
- **6-дневный прогноз** — отображение фаз луны на неделю вперёд
- **Цветовая индикация** — каждый тип фазы имеет свой цвет (🟢 отличный, 🟡 средний, 🔴 слабый)
- **Выбор даты** — возможность просмотра прогноза на любую дату через параметр `?date=YYYY-MM-DD`

#### 📰 Новости о рыбалке
На главной странице автоматически подгружаются свежие новости:
- **Парсинг Onliner** — HTML-парсинг раздела "Рыбалка" с извлечением заголовка, краткого описания, ссылки и изображения
- **Google News RSS** — получение новостей из RSS-ленты Google News по теме рыбалки
- **Объединение источников** — новости сортируются по дате и отображаются максимум 3 свежие
- **Резервные новости** — при ошибке парсинга показываются заготовленные новости-заглушки

#### 🔐 Регистрация и аутентификация
Реализована безопасная система регистрации:
- **Двухфакторная регистрация** — после ввода данных отправляется 6-значный код на email
- **Подтверждение email** — создание аккаунта только после ввода правильного кода
- **Вход по username или email** — можно войти, указав либо имя пользователя, либо email
- **Хеширование паролей** — пароли хранятся в хешированном виде (Werkzeug)
- **Сессии** — безопасное хранение состояния входа пользователя

#### 👤 Личный кабинет
В профиле пользователя реализовано:
- **История заказов** — отображение всех оформленных заказов с статусами
- **Информация о профиле** — username, email, Telegram ID для уведомлений
- **Смена аватара** — загрузка и отображение пользовательской аватарки
- **Статусы заказов** — отслеживание текущего статуса каждого заказа

#### 🚀 Оформление доставки
При оформлении заказа реализован выбор типа доставки:
- **Курьер** — ввод города и адреса доставки
- **Почта** — выбор отделения почты из списка с отображением адреса
- **Самовывоз** — выбор города для самовывоза из магазина

#### 🔔 Уведомления
После оформления заказа пользователь получает уведомление:
- **Email** — письмо с деталями заказа (номер, сумма, способ доставки)
- **Telegram** — сообщение в Telegram бот с аналогичной информацией
- **Сохранение Telegram ID** — при выборе Telegram-уведомлений ID сохраняется в профиль для будущих заказов

#### 🤖 RAG-бот для консультаций
На сайте реализован умный помощник для помощи покупателям:
- **Поиск по базе товаров** — бот ищет подходящие товары в БД магазина по запросу
- **Векторный поиск** — использование ChromaDB для семантического поиска по загруженным документам
- **Генерация ответов** — Google Gemini формирует развёрнутые ответы на основе найденного контекста
- **Рекомендации товаров** — при наличии подходящих товаров бот рекомендует их в первую очередь
- **Экспертный режим** — бот отвечает как опытный рыболов-консультант

### Для администраторов:

#### ➕ Управление товарами
В админ-панели реализовано полное управление ассортиментом:
- **Добавление товаров** — создание новых товаров с названием, ценой, категорией, описанием и изображением
- **Редактирование** — изменение всех параметров существующих товаров
- **Удаление товаров** — удаление товаров из каталога
- **Старая цена** — возможность указать зачёркнутую цену для отображения скидки
- **Загрузка изображений** — загрузка фото товаров с сохранением в Cloudinary

#### 📊 Управление заказами
Администратор может просматривать и обрабатывать заказы:
- **Список всех заказов** — таблица со всеми оформленными заказами
- **Детали заказа** — информация о пользователе, составе заказа, сумме и способе доставки
- **Смена статусов** — изменение статуса заказа (в обработке, доставлен, отменён и др.)

#### 📁 Загрузка документов в RAG
Администратор может пополнять базу знаний бота:
- **Загрузка PDF** — добавление PDF-документов (инструкции, руководства, статьи)
- **Загрузка TXT** — добавление текстовых файлов с информацией о товарах
- **Автоматическая индексация** — документы разбиваются на чанки и добавляются в ChromaDB
- **Обновление контекста** — бот сразу начинает использовать новые документы в ответах

      - postgres_data:/var/lib/postgresql/data

  postgres_data:

Запуск:
```bash
docker-compose up -d
```

## 🎯 Функционал

### Лунный календарь
Реализован алгоритм расчёта фазы луны на основе астрономических данных:
- **Базовая дата** — новолуние 7 января 1970 года (20:35)
- **Лунный цикл** — 29.53058770576 дней (сидерический месяц)
- **Расчёт** — вычисление количества дней, прошедших с базовой даты, и определение текущей фазы
- **6 фаз луны**:
  - 🌑 Новолуние (дни 0–1.84, 27.69–29.53) — слабый клёв
  - 🌒 Растущая луна (дни 1.84–5.53) — отличный клёв
  - 🌓 Первая четверть (дни 5.53–12.91) — средний клёв
  - 🌕 Полнолуние (дни 12.91–16.61) — слабый клёв
  - 🌗 Убывающая луна (дни 16.61–20.30) — отличный клёв
  - 🌘 Последняя четверть (дни 20.30–27.69) — средний клёв

### RAG-бот (Retrieval-Augmented Generation)
Система умного поиска и генерации ответов:

**Архитектура:**
1. **Векторизация текста** — модель `sentence-transformers/all-MiniLM-L6-v2` преобразует текст в 384-мерные векторы
2. **Хранение** — ChromaDB сохраняет векторы с метаданными для быстрого семантического поиска
3. **Поиск** — косинусное сходство между вектором запроса и документами находит релевантные чанки
4. **Генерация** — Google Gemini 2.5 Flash получает контекст и генерирует ответ на естественном языке

**Как это работает:**
- При запуске загружается документ `Fishing.txt` и разбивается на чанки по 200 слов с перекрытием 20 слов
- Каждый чанк векторизуется и сохраняется в коллекции `rag_chunks`
- При запросе пользователя:
  1. Поиск товаров в БД по названию/описанию/категории (LIKE-запрос)
  2. Семантический поиск по векторной базе (топ-5 чанков)
  3. Формирование промпта с контекстом из обоих источников
  4. Генерация ответа через Gemini API

**Команды бота:**
- `add_file <путь>` — загрузка нового документа (PDF или TXT) в базу знаний
- `exit` — завершение работы

### Новости
Два независимых источника с автоматическим слиянием:

**Onliner (HTML-парсинг):**
- Запрос с User-Agent браузера для обхода блокировок
- Поиск элементов с классами `news-tidings__item`, `news-header__item`
- Извлечение заголовка, ссылки, описания и изображения
- Обработка картинок из `background-image` в CSS-стилях

**Google News (RSS):**
- Подписка на RSS-ленту `/rss/topics/CAAqIggKIhxDQkFTRHdvSkwyMHZNREZuYkRVd0VnSnlkU2dBUAE`
- Парсинг через `feedparser`
- Извлечение изображения из HTML-содержимого `<img src="...">`
- Очистка текста от HTML-тегов через regex

**Обработка:**
- Сортировка по timestamp (сначала свежие)
- Ограничение до 3 новостей
- Fallback на заглушки при ошибке обоих источников

### Telegram-бот
Интеграция с Telegram для уведомлений:

**Отправка уведомлений:**
- POST-запрос на `https://api.telegram.org/bot{TOKEN}/sendMessage`
- Параметры: `chat_id` (Telegram ID пользователя) и `text` (текст сообщения)
- Формат сообщения: номер заказа, сумма, способ доставки

**Получение Telegram ID:**
- Пользователь может указать свой Telegram ID при оформлении заказа
- ID сохраняется в поле `tg_id` таблицы `users`
- При повторных заказах ID подставляется автоматически

### Доставка
Три типа доставки с разной логикой:

**Курьер:**
- Поля: город, адрес (улица, дом, квартира)
- Формат сохранения: `Курьер: {город}, {адрес}`

**Почта:**
- Выбор из предзагруженного списка отделений
- Поля: название почты, адрес отделения
- Формат сохранения: `{название} ({адрес})`

**Самовывоз:**
- Только выбор города
- Формат сохранения: `Самовывоз ({город})`

### Корзина
Хранение в сессии Flask (не в БД):

**Структура данных:**
```python
session['cart'] = [
    {'id': 1, 'quantity': 2},
    {'id': 5, 'quantity': 1}
]
```

**Функции:**
- `get_clean_cart()` — валидация и очистка корзины от некорректных данных
- `add_to_cart` — добавление товара или увеличение количества
- `update_cart` — увеличение/уменьшение количества на 1
- `remove_from_cart` — полное удаление товара

**Особенности:**
- Счётчик товаров в шапке сайта (через `@app.context_processor`)
- Сохранение между страницами через session
- Сброс после оформления заказа
